## Quiz Game Website

A fun and interactive **Quiz Game Website** designed to test users' knowledge through multiple-choice questions. The website provides an engaging quiz experience with a simple and user-friendly interface.

### Features

* Multiple-choice quiz questions
* Interactive question interface
* Score calculation
* Instant answer feedback
* Next-question navigation
* Final score/result display
* Responsive and user-friendly design

### Technologies Used

* HTML
* CSS
* JavaScript

### Project Objective

The main objective of this project was to practice **HTML, CSS, and JavaScript** while building an interactive web application with dynamic content, user interactions, and score management.
